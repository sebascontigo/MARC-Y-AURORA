Una práctica para hoy
«¿Qué parte de mi día elegí conscientemente?»

Reserva un momento para escribir tres decisiones que tomaste hoy. Junto a cada una, anota si respondió a un hábito, a una necesidad o a un valor importante para ti.

Después elige una sola acción distinta para mañana. No necesitas cambiarlo todo para empezar a observar.

Preguntas frecuentes

Antes de dar el siguiente paso.

Queremos que conozcas las opciones sin confundir aprendizaje, acompañamiento personal y asistencia clínica.

¿DESPIERTA y Soberanía Vital son el mismo programa?

No. Tienen responsables, contenidos y procesos distintos. Reconecta-T funciona como espacio de presentación común.

¿Es gratuito el intensivo de Aurora?

La propuesta inicial de siete días se presenta como gratuita. Las fechas, formato de entrega y plazas están pendientes de confirmación por el equipo.

¿Puedo sustituir atención médica o psicológica?

No. Estos contenidos tienen finalidad educativa y de desarrollo personal. Para síntomas o problemas de salud, consulta con profesionales sanitarios cualificados.

¿Cómo contacto con el equipo?

Desde esta web puedes abrir los perfiles públicos de Marc y Aurora en Instagram. La integración automática con GoHighLevel está pendiente.
