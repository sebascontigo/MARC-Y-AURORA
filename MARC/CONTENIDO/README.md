## Flujo de trabajo

```
01_IDEAS → 02_EN_PRODUCCION → 03_PARA_APROBAR → 04_APROBADO → 05_PUBLICADO
```

| Carpeta | Qué contiene | Quién mueve a la siguiente |
|---|---|---|
| `01_IDEAS` | Ideas sueltas, hooks, ángulos, repurpose de posts existentes | Agente |
| `02_EN_PRODUCCION` | Piezas con copy + asset asignado (imagen de `04_Instagram/ASSETS/IA_DRAFTS/`) | Agente |
| `03_PARA_APROBAR` | Piezas terminadas esperando OK de Marc/Sebastián | **Humano** |
| `04_APROBADO` | Piezas con visto bueno, listas para publicar | Agente publica |
| `05_PUBLICADO` | Piezas ya en IG (se archiva con fecha + URL) | Agente |
| `06_STORIES` | Copies de stories diarias (formato texto, no requieren asset) | Agente |
| `07_PLANTILLAS` | Plantillas reutilizables (CTA Despierta, estructura carrusel, etc.) | Agente |

## Reglas
- **No publicar nada sin pasar por `03_PARA_APROBAR`** (aprobación humana).
- Cada pieza = 1 archivo `.md` con: hook, copy, CTA, asset, hashtags, formato.
- Assets visuales: usar los 12 generados en `04_Instagram/ASSETS/IA_DRAFTS/` (revisión visual humana pendiente).
- Frecuencia objetivo: 3 reels/carruseles por semana + stories diarias.
