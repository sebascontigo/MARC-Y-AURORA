# 04_MAPA_DE_MARKETING_MARC

## Visión general
[CONFIRMADO] Marc quiere un sistema de captación razonado para ofertas high-ticket.
[CONFIRMADO] El proyecto incluye Meta Ads, Instagram, presencia digital y estructura para múltiples lanzamientos.

## Canal principal
[CONFIRMADO] Instagram aparece como canal principal para la fase inicial.
[CONFIRMADO] Facebook y YouTube aparecen como ampliación de alcance.

## Estrategia de contenidos
[CONFIRMADO] Se pretende reutilizar ángulos de contenido y repurpose para videos, carruseles y stories.
[CONFIRMADO] Hay un objetivo de “escarpe” visual y social proof antes del lanzamiento.

## Alineación de ads
[CONFIRMADO] Escala con Ads está montando oferta, embudo y campañas.
[INFERENCIA] El contenido orgánico debe reforzar la oferta y no competir con ella.

## Señales rojas
[NO CONSTA] No está definido quién crea los activos para cada canal.
[NO CONSTA] No aparece una estrategia final de contenidos con propietario claro.

## Oportunidad
[INFERENCIA] El proyecto puede mejorar mucho si se define una línea editorial clara, un calendario, un CRM y un reporte de métricas.
