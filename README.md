## Reglas de oro (NO NEGOCIABLES)
1. **No borrar ni sobrescribir historia.** Los chats, PDFs y auditorías previas son fuente de verdad.
2. **MARC y AURORA siempre separados** (activos, finanzas, estrategia, credenciales).
3. **Etiquetar todo:** [CONFIRMADO] [INFERENCIA] [PENDIENTE] [CONTRADICCIÓN] [OBSOLETO] [REQUIERE AUTORIZACIÓN].
4. **Nunca inventar datos ni cifras.** Si no hay dato: `NO DISPONIBLE` o `[POR CONFIRMAR]`.
5. **Credenciales = alto secreto.** Registrar solo SERVICIO/TIPO/UBICACIÓN/ESTADO. Nunca copiar valores a docs nuevos ni a Git.
6. **Pedir autorización antes de:** gastar dinero, contratar, campañas pagadas, borrar, cambiar contraseñas, contratos, publicaciones sensibles, cambios irreversibles.
7. **Agente solo-texto:** no generar/leer imágenes en el modelo; navegador por DOM/texto; los retos visuales (captcha) los resuelve el humano.
